# Glossary

- **Session** — one night (or part of a night) of play. Stored in the `sessions` tab (formerly `weeks`; code still uses `week_id`). Never "week" in UI copy.
- **Tonight** — the session whose status is `active`. Also the tab that shows it.
- **Commissioner** — the admin. Logs in with the shared password. UI copy says "Commissioner", never "Admin".
- **Team** — named after its captain ("Reid's team"; captain = alphabetically-first player). Identified visually by a **ball color** from its order in the session: 1 red, 2 green, 3 blue, 4 yellow.
- **Pallino** — the small target ball. Marks the standings leader.
- **Left early** — a departure (`player_departures`); player earns nothing in games after it.
- **Sat out** — a per-game exclusion (`game_player_exclusions`); player earns nothing for that one game.
- **Standings** — season leaderboard from closed sessions. Win = 4 pts, loss = 1.
